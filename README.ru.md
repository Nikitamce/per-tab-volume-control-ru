# Громкость по вкладкам (Per-Tab Volume Control RU)

**Language / Язык:** [English](README.md) | **Русский**

Расширение для Firefox: **отдельная громкость для каждой вкладки** (до **500%**), беззвучный режим, баланс стерео, моно и компрессор динамики.  
В этом репозитории — **русская локализация** сборки на базе **Per-Tab Volume Control 5.1.0**.

---

## Возможности

| Функция | Описание |
|--------|----------|
| **Громкость по вкладкам** | Независимый уровень **0–500%** для каждой вкладки |
| **Без звука** | Заглушить вкладку, не трогая системную громкость |
| **Баланс Л/П** | Сдвиг панорамы влево/вправо |
| **Моно** | Сведение стерео в моно |
| **Компрессор** | Сглаживание громких пиков (порог + степень) |
| **Другие вкладки** | Управление громкостью / mute / компрессором на других вкладках со звуком |
| **Глобальные настройки** | Значения по умолчанию для новых и перезагруженных страниц |
| **Горячие клавиши** | Громкость, сброс, mute, компрессор (настраиваются в Firefox) |
| **Светлая / тёмная тема** | Переключатель в шапке всплывающего окна |
| **Русский интерфейс** | Переведены popup, настройки, статусы и подписи команд |

## Установка (Firefox / Nightly)

Сборка **не подписана Mozilla**. Установить можно так.

### Вариант A — временная установка (удобно для проверки)

1. Откройте Firefox **Nightly**, **Developer Edition** или обычный Firefox.
2. Перейдите на `about:debugging` → **Этот Firefox**.
3. Нажмите **Загрузить временное дополнение…**.
4. Выберите:
   - `manifest.json` в корне репозитория, или  
   - `dist/per-tab-volume-control-ru-5.1.0.xpi`.
5. На панели появится значок — нажмите, чтобы открыть панель управления.

Временные дополнения снимаются после перезапуска Firefox (можно загрузить снова тем же способом).

### Вариант B — постоянная неподписанная установка (продвинутый)

Только в профилях, где разрешены неподписанные дополнения, например:

- Nightly / Developer Edition с  
  `xpinstall.signatures.required` = `false` в `about:config`, или  
- корпоративные / policy-профили.

Затем установите `.xpi` через менеджер дополнений или перетаскиванием.

> **Важно:** в обычном release Firefox для постоянной установки Mozilla требует подпись дополнения.

### Вариант C — своя сборка XPI

В путях внутри XPI нужны **прямые слэши** `/` (не Windows `\`).  
Готовый файл лежит в `dist/`. Либо загружайте **папку** через `about:debugging` без упаковки.

## Как пользоваться

1. Откройте сайт с HTML5 audio/video.
2. Нажмите значок расширения.
3. Двигайте **ползунок громкости** (0–500%) или введите проценты.
4. По желанию:
   - **Без звука** — заглушить вкладку  
   - **Моно** — монофония  
   - **Баланс** — Л / П  
   - **Компрессор** — включить и настроить порог / степень  
   - **Другие вкладки** — управление вкладками со звуком  
5. **Настройки** (шестерёнка):
   - страница горячих клавиш Firefox  
   - глобальное вкл/выкл расширения  
   - глобальные компрессор / моно / баланс  

### Горячие клавиши по умолчанию

| Действие | Сочетание |
|----------|-----------|
| Громче | `Alt+Shift+Up` |
| Тише | `Alt+Shift+Down` |
| Сброс громкости | `Alt+Shift+R` |
| Без звука / звук | `Alt+Shift+M` |
| Компрессор вкл/выкл | `Alt+Shift+C` |

Настройка: **Настройки → Расширения → Управление сочетаниями клавиш** или экран **Горячие клавиши** в popup.

## Разрешения

| Разрешение | Зачем |
|------------|--------|
| `activeTab` / `tabs` | Определять вкладки и применять настройки |
| `scripting` | Скрипты на страницах для управления звуком |
| `storage` | Сохранять громкость и предпочтения |
| `<all_urls>` | Работа со звуком на открываемых сайтах |

В этой локализованной сборке **не добавлялась** отправка данных на внешние серверы аналитики.

## Решение проблем

| Проблема | Что сделать |
|----------|-------------|
| **«Файл не найден» для `popup/popup.html`** | XPI собран с путями `\`. Берите `dist/*.xpi` из этого репо или грузите `manifest.json` из папки. |
| «Нельзя обнаружить/управлять звуком» | Ограниченная страница или нужна перезагрузка после установки. |
| Компрессор / моно / баланс недоступны | Сайт в упрощённом режиме (CORS и т.п.); громкость и mute часто всё ещё работают. |
| После перезапуска Firefox дополнения нет | Для временной установки это нормально — загрузите снова через `about:debugging`. |
